# Podman

## Containers

A collection of containers running Alpine Linux for the 64-bit architectures ARM (aarch64), PowerPC (ppc64le), and RISC-V.

- alpine-aarch64.tar
- alpine-ppc64le.tar
- alpine-riscv64.tar

## Configurations

Local configuration files.

- qemu-binfmt.service
- qemu-binfmt-conf.sh - Local copy of [QEMU](https://github.com/qemu/qemu/blob/master/scripts/qemu-binfmt-conf.sh)

## Installation

Batch for air-gapped installation.

- alpine-load.cmd
